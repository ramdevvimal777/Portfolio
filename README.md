# Portfolio Website
## Project Description

This project is personal portfolio created for the Web and Script Programming course.

The websit was craeted using HTML5 and CSS3 and contains four seperate webpages:
- Home
- About Me
- Projects
- Contact Me

The main purpose of this website is to introduce myself, display 
some of the projects i have completed, and to provide a way for visitors to contact me.

##  Responsive Design
The website uses a fluid responsive design with separate CSS files for different screen sizes.

The viewport sizes used are:
-Mobile: 480px and below
-Tablet: 481px to 960px
Laptop/Desktop: 961px and above

These dimensions were selected to that the layout can adjust depending on the size of the user's screen.

The following CSS files are used:

- common.css - Contains styles shared by all screen sizes.
- mobile.css - Contains styles for mobile devices.
- tablet.css - Contains styles for tablets.
- laptop.css - Contains styles for laptops and desktop computers.

  Percentages and relative measurements are used in different parts of the website to help make the design responsive.

  ## Colour Scheme
  The website uses a blue, navy and purple colour scheme selected using adobe Color.

  The Colors used are:
- Navy            :#1B263B
- Deep Blue       : #2B5876
- Purple          : #4E4376
- Light Blue-Grey : #E9EEF2
- White           : #FFFFFF

  Navy snd blue are main;y used for navigation, headings, buttons, and other important elements.
  Purple is used as a secondary and accent color. Light-blue-gray is used for the page background,
  while white is used for the main content area.
  The same colour scheme is used throughout the website to maintain a consistent appearance.

  ## Gradients
  Two types od CSS linear gradients are used in the website.
  
 - An angles linear gradient is used in the header:
         background: linear-gradient(45deg,#2b5876,#4e4376);
  This creates a diagonal transition between deep blue and purple.
  
  - A horizontal linear gradient is used in the footer:
         background: linear-gradient(to right, #1B263B,#2b5876);
  This creates a transition from navy to deep blue from left to right.
  
  The gradients were used to make the header and footer visually
  different from the main content while keeping the website's colour scheme consistent.
